# Xapo

> Xapo Bank is a members-only, Gibraltar-regulated private bank and Bitcoin custodian (founded 2013). Members earn interest on Bitcoin and USD, borrow against Bitcoin, invest in US stocks, and transact globally — all app-only. Xapo Bank publishes no public developer API or portal today; its legacy Bitcoin Wallet API (developers.xapo.com) was retired. Regulated by the GFSC: Xapo Bank Limited as a credit institution (No. 23171), Xapo VASP Limited as a DLT Provider (No. 26061). Publishes SOC 2 Type II / SOC 3, PCI DSS, and GDPR compliance claims.

## APIs

Xapo Bank exposes no public developer API. Legacy hosts (developers.xapo.com, docs.xapo.com, api.xapobank.com) no longer resolve; api.xapo.com returns 404. Legacy SDKs from the pre-bank wallet era remain on registries:

- [xapo_sdk on PyPI](https://pypi.org/project/xapo-sdk/): legacy Xapo bitcoin SDK 0.2.2 (retired API)
- [xapo_sdk on RubyGems](https://rubygems.org/gems/xapo_sdk): legacy Xapo bitcoin SDK 0.2.2 (retired API)
